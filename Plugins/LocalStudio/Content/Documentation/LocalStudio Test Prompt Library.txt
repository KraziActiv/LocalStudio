Parameterized Landscape (Detailed Style)
Create a landscape to be a foggy horror valley with these settings:

Flat, open valley floors for base building (valley_flattening: 0.5)

Steep, jagged cliff mountains (elevation_scale: 18000.0, slope_power: 1.8, noise_scale: 0.0015)

Mountain plateaus (plateau_clamping: 0.85)

Rolling hills, shallow slopes, and water features (rivers, lakes, ocean beach)

4. Character Architecture & Metabolism (C++)
Simple Master Character Prompt
Create a MasterCharacter class for a multiplayer survival game that will be used as a parent for both Player and AI characters. Place it in the MasterFiles folder.

Simple Metabolism Character Prompt
Create a base character class called AMasterCharacter in MasterFiles. Give it a SCUM-style metabolism system with core vitals, macronutrients, and replication support for a multiplayer game.

Technical Production Character Prompt (Detailed Architecture)
Create a production-ready C++ base character class AMasterCharacter for Unreal Engine 5 designed for multiplayer games, serving as the parent class for both playable characters and AI NPCs. Place this file in MasterFiles.

Implement a SCUM-style metabolism and nutrition system with full network replication:

Core Vitals: Health, Stamina, Exhaustion, Body Mass (Weight/BMI), and Blood Pressure/Heart Rate.

Nutrition: Macronutrients (Calories, Proteins, Carbs, Fats, Fiber, Hydration) and Micronutrients (Vitamins A, B, C, D, and Minerals). Include digestion logic that processes food buffers over time.

Replication: Server-to-client replication with GetLifetimeReplicatedProps and OnRep handlers. Set bReplicates = true.

Inheritance & Accessors: Native ACharacter setup with capsule root, blueprint-callable getters, and server ingestion functions.

Stats Component (Basic)

Stats Component (Advanced Progression & Vitals)

Dedicated Health Component (RPC Damage)

UI Progress Bar Integration
Create a UUserWidget C++ class named UPlayerHUDWidget in the UI folder. It should take a reference to a UStatsComponent and expose functions or delegates to update Health and Stamina progress bars.

System Integration / Linking Prompt
